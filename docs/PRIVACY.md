# Public Publication Boundary

Public material uses project names and public handles rather than personal names. Private correspondence, health narratives, local saves, real contact details, credentials, and unrelated archives are excluded.

No claim is made that replacing a name alone anonymizes a private record. Private source records are not published, even with names scrambled.

Fictional characters, illustrative sample notes, Unicode code points, game numbers, and version numbers are not personal contact information.

Future contributions must receive the same review. Commit metadata uses a public handle and GitHub's generated no-reply address rather than a personal email address. The initial public history is created from reviewed files only; private draft history is not pushed.
